SOURCE PACKAGE

Main TeX file: courtade-kumar.tex
Compiler: pdfLaTeX

All required source files, the IEEEtran class, and both PDF figures are in
this directory. No external bibliography processing is required because the
bibliography is contained in references.tex.

The optional numerical consistency checks can be run with:

    python3 numerical_diagnostics.py

The author list and the Generative AI Disclosure are contained in
courtade-kumar.tex and ai-disclosure.tex, respectively.
